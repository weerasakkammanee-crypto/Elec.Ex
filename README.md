## 🐛 แก้เฉลยผิด 4 ข้อ (หมวดคอมพิวเตอร์) + ตัดข้อที่ภาพหายไป 19 ข้อ + ซ่อมข้อความปนกัน 3 ข้อ

**เฉลยผิด (หมวดคอมพิวเตอร์เบื้องต้น) แก้แล้ว 4 ข้อ:** ตรวจสอบย้อนกลับไปที่ไฟล์ต้นฉบับพบว่าข้อ "โปรแกรมวินโดวส์ เป็นซอฟต์แวร์ประเภทใด" มีอยู่ในต้นฉบับ 2 ครั้งและเฉลยขัดแย้งกันเอง (ครั้งหนึ่งเฉลยผิด อีกครั้งเฉลยถูก) ระบบไปหยิบครั้งที่ผิดมาใช้ — แก้เป็นเฉลยที่ถูกต้องแล้ว (Windows = ซอฟต์แวร์ระบบ) ส่วนอีก 3 ข้อ (ความหมายของคำว่าคอมพิวเตอร์ 2 ข้อ + ข้อดีของคอมพิวเตอร์) ตรงกับต้นฉบับ 100% แต่ขัดกับความรู้ทั่วไปทาง IT จึงแก้ตามคำยืนยันจากผู้ดูแลระบบ

**ภาพหายไป — ตรวจทั้งคลังแล้ว ตัดออก 19 ข้อ:** พบว่าบางคำถามอ้างอิงรูปภาพ/แผนภาพ/แถบสีตัวต้านทานที่ไม่มีไฟล์ภาพแนบมาด้วย (สูญหายตั้งแต่ตอนแปลงไฟล์ต้นฉบับ) ทำให้ตอบไม่ได้จริง เช่น "จากรูปเป็นสัญลักษณ์ของอุปกรณ์อิเล็กทรอนิกส์..." หรือคำถามกลุ่มที่อ้างอิง "ข้อ 7-9"/"ข้อ 24-26" ที่ใช้ภาพร่วมกัน (ใช้ไม่ได้อยู่แล้วเมื่อระบบสุ่มลำดับข้อ) — ตัดออกจากคลัง 19 ข้อ (basic 8, rlc 6, radio 4, circuit 1) เพื่อไม่ให้ผู้เข้าสอบเจอคำถามที่ตอบไม่ได้

**ข้อความคำถามปนกัน ซ่อมแล้ว 3 ข้อ:** พบคำถาม 3 ข้อที่ตอนแปลงไฟล์ต้นฉบับ มีข้อความจากคำถามข้อก่อนหน้าหลุดมาปนอยู่ในเนื้อคำถามอีกข้อ (แต่ตัวเลือก/เฉลยที่เก็บไว้ยังถูกต้องสมบูรณ์ ไม่ต้องใช้ภาพประกอบ) จึงตัดข้อความส่วนที่ปนกันออก เหลือแต่คำถามที่ตอบได้จริงและตรงกับตัวเลือก/เฉลยที่มี

คลังข้อสอบหลังตัดออกเหลือ **1,218 ข้อ** (จากเดิม 1,237)

**การอัปเดต**: รอบนี้แก้ **ทั้งฝั่งเว็บและฝั่งเซิร์ฟเวอร์** (คลังข้อสอบเปลี่ยนจำนวนและเนื้อหา) ต้องทำครบ 2 ขั้นตอนเหมือนเดิม

## 🐛 แก้ปัญหา iOS: หน่วง / เชื่อมต่อเซิร์ฟเวอร์บ่อย / อ่านหน้าเนื้อหาไม่ได้ + ปรับขั้นตอนเริ่มทำข้อสอบ + ตัดข้อที่อ้างอิงข้อก่อนหน้า

**1. หน้าเนื้อหาอ่านไม่ได้บน iOS (สาเหตุหลัก, พบแล้ว):** แอปสลับหน้าจอโดยไม่เลื่อนกลับขึ้นบนสุด — Chrome/Android มีกลไก "scroll anchoring" ช่วยชดเชยให้อัตโนมัติ แต่ Safari/iOS ไม่มี ผลคือเปิดหน้าเนื้อหาใหม่แล้วจอยังค้างเลื่อนอยู่ตำแหน่งเดิมจากหน้าก่อน (โดยเฉพาะถ้าก่อนหน้านี้เลื่อนดูรายการเนื้อหาลงมา) ทำให้ดูเหมือนหน้าว่างเปล่า/อ่านไม่ได้ **แก้แล้ว**: ทุกครั้งที่เปลี่ยนหน้าจะเลื่อนจอกลับขึ้นบนสุดให้อัตโนมัติ

**2. หน่วง / เชื่อมต่อเซิร์ฟเวอร์บ่อย:** ปรับ 3 จุด — (ก) เพิ่มระบบลองเชื่อมต่อใหม่อัตโนมัติเงียบๆ เมื่อเน็ตสะดุดชั่วครู่ (เฉพาะการเรียกที่อ่านข้อมูลอย่างเดียว ปลอดภัยที่จะลองซ้ำ) แทนที่จะขึ้น error ให้ผู้ใช้เห็นทันที (ข) ลดความถี่การเช็คเซสชันพื้นหลังระหว่างทำข้อสอบจากทุก 15 วิ เหลือทุก 30 วิ ลดจำนวนการเชื่อมต่อแย่งกับ request จริง (ค) นาฬิกาจับเวลาสอบเปลี่ยนมาคำนวณจากเวลาจริง (wall-clock) แทนการนับถอยหลังทีละวินาที เพราะ iOS มักหน่วง/หยุด timer เวลาสลับแอปหรือพับหน้าจอ ทำให้ตัวเลขเวลาคลาดเคลื่อนจากความเป็นจริง — ตอนนี้พอกลับมาเปิดแอปจะรีเฟรชเวลาให้ตรงทันที

**3. ปรับขั้นตอนเริ่มทำข้อสอบ (ฝึกทำ):** เดิมกดปุ่มลัด "10/20/30/ทั้งหมดข้อ" แล้วเริ่มทำทันที ตอนนี้ปุ่มลัดจะแค่เติมจำนวนข้อในช่องกรอกให้ ผู้เข้ารับการทดสอบต้องกดปุ่ม **"▶ เริ่มฝึกทำ"** เองอีกครั้งเพื่อเริ่มจริง (ยังกำหนดจำนวนข้อ/เวลาเองในช่องกรอกได้เหมือนเดิม) — โหมดจำลองสอบมีขั้นตอนกดเริ่มแยกต่างหากอยู่แล้วไม่ต้องแก้

**4. ตัดข้อสอบที่อ้างอิง "ข้อก่อนหน้า" ออก 5 ข้อ:** ตรวจพบว่ามีคำถาม 5 ข้อในคลัง (เช่น "จากข้อก่อนหน้า...", "จากโจทย์ข้อ 29...") ที่เขียนแบบอ้างอิงเนื้อหา/คำตอบจากข้อที่อยู่ติดกัน ซึ่งใช้งานไม่ได้เมื่อระบบสุ่มลำดับข้อสอบให้แต่ละคน (ข้อที่อ้างอิงถูกแยกออกจากข้อต้นทาง) จึงตัดออกจากคลังทั้ง 5 ข้อ (basic 1 ข้อ, rlc 4 ข้อ) เหลือ**คลังข้อสอบรวม 1,237 ข้อ** (จากเดิม 1,242) ทุกข้อที่เหลือเป็นข้อความสมบูรณ์ในตัวเอง ไม่มีการอ้างอิงข้อคำถามอื่นอีกต่อไป

**การอัปเดต**: รอบนี้แก้ **ทั้งฝั่งเว็บและฝั่งเซิร์ฟเวอร์** (คลังข้อสอบเปลี่ยนจำนวน) ต้องทำครบทั้ง 2 ขั้นตอนเหมือนอัปเดตครั้งก่อนๆ (ดูขั้นตอน A/B ด้านล่าง) — วางไฟล์ `server/apps_script_code.gs` ชุดใหม่ทับใน Apps Script + Deploy เวอร์ชันใหม่ แล้วอัปโหลด `index.html` ชุดใหม่ทับใน GitHub repo

## 🐛 แก้บั๊ก: ขึ้น "บัญชีนี้ถูกล็อกอินจากอุปกรณ์อื่น" ทั้งที่ไม่ได้ล็อกอินที่อื่น

**อาการ**: ระหว่างทำข้อสอบไปสักพัก (ทำไปเกินครึ่งแล้ว) จู่ๆ ถูกเด้งออกมาหน้าแรกพร้อมข้อความ "บัญชีนี้ถูกล็อกอินจากอุปกรณ์อื่น เซสชันนี้จึงถูกตัดออก" ทั้งที่ไม่ได้เข้าที่ไหนอีกเลย

**สาเหตุที่แท้จริง**: แอปมีระบบเช็คทุก 15 วินาทีระหว่างทำข้อสอบว่าบัญชียังเป็นเซสชันที่ใช้งานอยู่ไหม (กันคนอื่นแอบใช้บัญชีเดียวกันพร้อมกัน) แต่โค้ดเดิม**ตีความ error ทุกชนิดว่าคือ "ถูกล็อกอินที่อื่น" หมด** — รวมถึงเน็ตสะดุดชั่วครู่ หรือเซิร์ฟเวอร์ (Google Apps Script) ตอบช้า/error ชั่วคราว ซึ่งเกิดได้เป็นปกติเวลาใช้งานต่อเนื่องนานๆ ผ่านมือถือ/เน็ตที่ไม่เสถียร ทำให้ถูกเด้งออกทั้งที่ไม่มีใครแอบล็อกอินจริง

**วิธีแก้**: แก้ให้แอปแยกแยะ error แต่ละแบบ — เฉพาะกรณีเซิร์ฟเวอร์ยืนยันชัดเจนว่า token ไม่ตรง (ถูกล็อกอินที่อื่นจริง) หรือบัญชีถูกระงับ เท่านั้นถึงจะเด้งออก และต้องเจอซ้ำ 2 ครั้งติดต่อกัน (ห่างกัน 15 วิ) ก่อนถึงจะตัดออกจริง ส่วน error ชั่วคราวอื่นๆ (เน็ตหลุด/เซิร์ฟเวอร์ error ชั่วคราว) จะถูกข้ามไปเฉยๆ แล้วเช็คใหม่รอบถัดไปแทน ไม่ทำให้ถูกเตะออกกลางคัน — ทดสอบยืนยันแล้วด้วย automated test ทั้ง 3 เคส (error ชั่วคราวไม่เด้ง / เด้งครั้งเดียวยังไม่ตัด / ยืนยันซ้ำ 2 ครั้งถึงตัดออกจริง)

**การอัปเดต**: แก้เฉพาะฝั่งเว็บ (`index.html`) เท่านั้น **ไม่ต้องแตะ Apps Script เลย** — แค่เข้า GitHub repo `chang-e-exam` → อัปโหลดไฟล์ `index.html` ชุดใหม่ในแพ็กเกจนี้ทับที่ root repo เหมือนเดิม รอ Netlify deploy เสร็จ (1-2 นาที) ก็เรียบร้อย ข้อมูลสมาชิก/คะแนนเดิมไม่กระทบ

## 🆕 อัปเดตล่าสุด: คลังข้อสอบขยายจาก 130 → 1,242 ข้อ + เพิ่ม 5 หมวดวิชาใหม่ + 3 ฟีเจอร์ใหม่ในแอป

**ฟีเจอร์ใหม่ในตัวแอป (ไม่ต้องเปิดไฟล์ Word แยก):**

1. **📖 เนื้อหาอ่านทบทวน** — เมนูใหม่ที่หน้าแรก รวมสรุปเนื้อหา 4 เรื่อง: หลักนิยมการสื่อสาร, ไฟฟ้า/อิเล็กทรอนิกส์เบื้องต้น, ไวยากรณ์ภาษาอังกฤษ, ตรีโกณมิติ+จำนวนเชิงซ้อน — **ผู้ที่ยังไม่เข้าสู่ระบบเห็นได้แค่ตัวอย่างบางส่วน (~35% แรกของแต่ละเรื่อง)** พร้อมปุ่มเข้าสู่ระบบ/สมัครสมาชิก ต้องเข้าสู่ระบบด้วยบัญชีที่แอดมินอนุมัติแล้วเท่านั้นถึงจะอ่านเนื้อหาเต็มทุกเรื่องได้
2. **เหตุผลประกอบเฉลย** — โหมดฝึกทำ: หลังเลือกคำตอบแล้วนอกจากจะขึ้นถูก/ผิดทันที ข้อไหนมีคำอธิบายเหตุผลจะแสดงต่อท้ายให้อ่านได้เลย (ประมาณ 440 ข้อในคลังมีเหตุผลกำกับ) หน้าสรุปคะแนนท้ายการทำข้อสอบก็แสดงเหตุผลกำกับทุกข้อที่มีเช่นกัน
3. **ปรับจำนวนข้อ/เวลา/วิชาได้เอง** ทั้งโหมดฝึกทำและโหมดจำลองสอบ:
   - **โหมดฝึกทำ**: นอกจากปุ่มลัด 10/20/30/ทั้งหมดแบบเดิม ตอนนี้มีช่อง "กำหนดจำนวนข้อเอง" พิมพ์จำนวนข้อได้อิสระ พร้อมติ๊กเลือก "จับเวลาด้วย" แล้วระบุจำนวนนาทีได้ (เดิมฝึกทำไม่มีจับเวลาเลย)
   - **โหมดจำลองสอบ**: เปลี่ยนจากกดเริ่มทันที (ตายตัว 50 ข้อ/60 นาที/ทุกวิชา) เป็นหน้า "ตั้งค่าจำลองสอบ" — ติ๊กเลือกวิชาที่ต้องการสอบได้เอง (มีปุ่ม "เลือกทุกวิชา"/"ไม่เลือกเลย" ช่วย) พิมพ์จำนวนข้อและเวลาสอบ(นาที)ได้อิสระ ถ้าใส่จำนวนข้อเกินกว่าที่มีจริงในวิชาที่เลือก ระบบจะปรับลดให้อัตโนมัติไม่ error

รอบนี้ได้ดึงข้อสอบที่เหลือทั้งหมดจากโฟลเดอร์ต้นฉบับมาเพิ่ม (ตัดข้อซ้ำออกแล้ว) ครอบคลุมทุกวิชาที่พบ ไม่ใช่แค่ไฟฟ้า/อิเล็กทรอนิกส์ **เนื่องจากมีคุณติดตั้งระบบไว้แล้ว ไม่ต้องทำขั้นตอน A–C ใหม่ทั้งหมด ทำแค่ 2 ข้อนี้พอ:**

1. **อัปเดตฝั่งเซิร์ฟเวอร์**: เปิด Apps Script editor ของโปรเจกต์เดิม (ผ่าน Google Sheet → Extensions → Apps Script) → **ลบโค้ดเดิมทั้งหมดใน `Code.gs`** → วางเนื้อหาไฟล์ `server/apps_script_code.gs` ชุดใหม่ที่แนบมาทับลงไป → Ctrl+S → **Deploy → Manage deployments → ไอคอนดินสอ → Version: "New version" → Deploy** (ขั้นตอนนี้จำเป็นเสมอ ข้ามไม่ได้ ไม่งั้นโค้ดใหม่จะไม่มีผลจริง)
2. **อัปเดตฝั่งเว็บ**: เข้า GitHub repo `chang-e-exam` เดิม → ลบไฟล์ `index.html` เก่าออก (หรือกด edit แล้วแทนที่เนื้อหาทั้งหมด) → อัปโหลดไฟล์ `index.html` ชุดใหม่ที่แนบมาทับที่ root ของ repo เหมือนเดิม — Netlify จะ deploy เวอร์ชันใหม่ให้อัตโนมัติภายในไม่กี่นาที (ไม่ต้องแตะการตั้งค่า Netlify ใดๆ)

จากนั้นเปิดเว็บ รอ 1-2 นาทีแล้วรีเฟรช เช็คว่าท้ายหน้า login ขึ้น **สีเขียว "เซิร์ฟเวอร์เป็นโค้ดล่าสุด"** และหน้าแรกโชว์ตัวเลข **"1,242 ข้อ"** ก็ใช้งานได้ทันที — ไม่ต้องรัน `setupSheets` ใหม่ ข้อมูลสมาชิก/ประวัติคะแนนเดิมยังอยู่ครบ (อยู่คนละส่วนกับคลังข้อสอบ)

นอกจากนี้ยังแนบไฟล์ **`CHANG-E_EXAM_เนื้อหาเสริม_และเฉลยพร้อมเหตุผล.docx`** มาให้แยกต่างหาก — เป็นเอกสาร Word สำหรับอ่านทบทวน ไม่เกี่ยวกับการ deploy เว็บ (รายละเอียดดูหัวข้อท้ายไฟล์นี้)

## ภาพรวมระบบ (3 ส่วน)

1. **ไฟล์เว็บ (Client)** — `index.html` ไฟล์เดียว มีคำถามตัวอย่างฟรี 30 ข้อฝังอยู่ (ทดลองทำได้ทันทีไม่ต้องล็อกอิน) ส่วนคลังข้อสอบเต็ม 130 ข้อ **ไม่ได้ฝังอยู่ในไฟล์นี้** ต้องดึงจากเซิร์ฟเวอร์เท่านั้น
2. **เซิร์ฟเวอร์ (Backend)** — Google Apps Script Web App (`server/apps_script_code.gs`) เก็บคลังข้อสอบเต็มทั้งหมด ระบบสมาชิก (สมัคร/ล็อกอิน/เซสชัน) และประวัติคะแนน ผูกกับ Google Sheet ใหม่ที่มีชีต `Users` และ `Attempts`
3. **การโฮสต์เว็บ (Hosting)** — GitHub repo ใหม่ (มีแค่ `index.html` + โฟลเดอร์ `assets/images/`) เชื่อมกับ Netlify แบบ continuous deployment

ไฟล์ที่แนบมาให้ในแพ็กเกจ:
- `index.html` — ไฟล์เว็บพร้อมอัปโหลด (ยังไม่ได้ฝัง URL เซิร์ฟเวอร์จริง ดูขั้นตอน A แล้วส่ง URL กลับมาให้ผมฝังให้)
- `assets/images/` — รูปภาพประกอบคำถาม 19 ไฟล์ (ต้องอัปโหลดคู่กับ index.html เสมอ)
- `server/apps_script_code.gs` — โค้ดฝั่งเซิร์ฟเวอร์ (**ห้ามอัปโหลดขึ้น GitHub** วางในหน้า Apps Script เท่านั้น)

## ขั้นตอน A — สร้าง Google Sheet + Backend (Apps Script)

1. เปิด [sheets.google.com](https://sheets.google.com) → สร้างสเปรดชีตใหม่ (ว่างเปล่า) → ตั้งชื่อเช่น **"CHANG-E EXAM DB"**
2. เมนู **Extensions (ส่วนขยาย) → Apps Script**
3. ลบโค้ดเริ่มต้นในไฟล์ `Code.gs` ทั้งหมด แล้ว **วางเนื้อหาไฟล์ `server/apps_script_code.gs` ที่แนบมาทับลงไปทั้งหมด**
4. หาบรรทัด `var ADMIN_KEY = 'CHANGE-THIS-ADMIN-KEY-BEFORE-DEPLOY';` แล้ว **เปลี่ยนเป็นรหัสลับที่ตั้งเอง** (จำให้แม่น จะใช้เข้าเมนูแอดมินของเว็บ) — ห้ามบอกรหัสนี้กับใครนอกจากผู้ดูแลระบบ
5. กด Ctrl+S บันทึก ตั้งชื่อโปรเจกต์เช่น "CHANG-E EXAM Backend"
6. ที่ dropdown เลือกฟังก์ชันด้านบน (ข้าง Debug) เลือก **`setupSheets`** แล้วกด **Run** ครั้งเดียว
   - ครั้งแรกจะมีหน้าต่างขอ authorize สิทธิ์ → กด **Allow**
   - ถ้าขึ้นเตือน "Google hasn't verified this app" → กด **Advanced** แล้วเลือก **"Go to [ชื่อโปรเจกต์] (unsafe)"** ได้ตามปกติ เพราะเป็นสคริปต์ของเราเอง
   - เสร็จแล้วกลับไปเช็คที่สเปรดชีต ต้องเห็นชีตชื่อ **Users** และ **Attempts** ถูกสร้างขึ้นแล้ว
7. เมนู **Deploy → New deployment** → คลิกไอคอนเฟือง เลือกประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด **Deploy**
8. คัดลอก URL ที่ได้ (ลงท้ายด้วย `/exec`)
9. **ส่ง URL นี้กลับมาให้ผม (Claude)** เพื่อฝังลงไฟล์ `index.html` ให้สมบูรณ์ก่อนนำไปอัปโหลดขึ้น GitHub ในขั้นตอน B

> ทุกครั้งที่แก้โค้ด `.gs` ในอนาคต ต้องกลับมาที่ Deploy → Manage deployments → ไอคอนดินสอ → Version เลือก **"New version"** → Deploy ใหม่เสมอ (ข้ามขั้นตอนนี้ = โค้ดใหม่ไม่มีผลจริง)

## ขั้นตอน B — สร้าง GitHub repo ใหม่ + เชื่อม Netlify

1. สร้าง repository ใหม่บน GitHub ชื่อ **`chang-e-exam`** (แยกจาก `jsor-exam` เดิมโดยสิ้นเชิง)
2. อัปโหลดไฟล์ **`index.html`** (เวอร์ชันที่ผมฝัง URL เซิร์ฟเวอร์ให้แล้วตามขั้นตอน A) ไว้ที่ **root** ของ repo โดยตรง
3. อัปโหลดโฟลเดอร์ **`assets/images/`** ทั้งหมด (19 ไฟล์) ไว้ที่ path เดิมคือ `assets/images/` ใน repo — จำเป็นเพราะคำถามในคลังเต็มอ้างอิงรูปจากพาธนี้
   - วิธีที่ทำงานได้ดีที่สุด: หน้าหลักของ repo → **"Add file" → "Upload files"** → ลากทั้งไฟล์ `index.html` และไฟล์ในโฟลเดอร์ `assets/images/` ไปพร้อมกัน (GitHub เว็บจะสร้างโฟลเดอร์ให้อัตโนมัติถ้าลากทั้งโฟลเดอร์ หรือพิมพ์ path `assets/images/ชื่อไฟล์` นำหน้าตอนอัปโหลดทีละไฟล์)
   - **ห้ามอัปโหลดโฟลเดอร์ `server/`** ขึ้น GitHub — โค้ดฝั่งเซิร์ฟเวอร์วางในหน้า Apps Script เท่านั้น ไม่ควรเผยแพร่สาธารณะ
4. เลื่อนลงกด **Commit changes**
5. ไปที่ [app.netlify.com](https://app.netlify.com) → **Add new site → Import an existing project** → เลือก GitHub → เลือก repo `chang-e-exam` → Deploy (ไม่ต้องตั้งค่า build command ใดๆ เพราะเป็น static file เดี่ยว)
6. หลัง deploy เสร็จ เข้า **Site configuration → Sharing/Visitor access** เช็คว่าตั้งเป็น **Public** แล้ว (โปรเจกต์ใหม่บางครั้งตั้ง Private by default ทำให้คนอื่นเข้าเว็บไม่ได้เลย)
7. เปิด URL ของเว็บที่ Netlify ให้มา เลื่อนไปดูข้อความเล็กๆ ท้ายหน้า login — ต้องขึ้น **สีเขียว "เซิร์ฟเวอร์เป็นโค้ดล่าสุด"** แปลว่าทั้งสองฝั่งเชื่อมกันสำเร็จ

## ขั้นตอน C — ทดสอบใช้งานจริงก่อนเปิดให้คนอื่นใช้

1. สมัครสมาชิกทดสอบ 1 บัญชีจากหน้าเว็บจริง
2. กด **"⚙️ สำหรับผู้ดูแลระบบ"** ที่หน้า login → ใส่ `ADMIN_KEY` ที่ตั้งไว้ในขั้นตอน A ข้อ 4 → กด **อนุมัติ** บัญชีทดสอบ
3. กลับไปล็อกอินด้วยบัญชีทดสอบ → ลองทั้ง **โหมดฝึกทำ** (เลือกหมวดหมู่ + ดูรูปประกอบคำถามที่มีภาพ) และ **โหมดจำลองสอบ** (จับเวลา 50 ข้อคละหมวด)
4. เช็คหน้า **ประวัติคะแนน** ว่าบันทึกผลถูกต้อง
5. ลองล็อกอินซ้อน 2 หน้าต่างด้วยบัญชีเดียวกัน → เซสชันแรกต้องถูกเตะออกอัตโนมัติ (ทดสอบ single-active-session)

## เกี่ยวกับเอกสารเสริม (Word)

ไฟล์ `CHANG-E_EXAM_เนื้อหาเสริม_และเฉลยพร้อมเหตุผล.docx` (~100 หน้า) แบ่งเป็น 4 ส่วน:

1. **เนื้อหาสรุปอ่านทบทวน** — หลักนิยมการสื่อสาร, ไฟฟ้า/อิเล็กทรอนิกส์เบื้องต้น, ไวยากรณ์อังกฤษ, ตรีโกณมิติ+จำนวนเชิงซ้อน
2. **เฉลยข้อสอบพร้อมเหตุผล** — สำหรับข้อสอบ ~510 ข้อ (คณิต 3 ชุด, อังกฤษ, เครื่องรับวิทยุ, ไฟฟ้ากระแสตรง-สลับ) ที่ไฟล์ต้นฉบับไม่มีเฉลยแนบมา จึงวิเคราะห์หาคำตอบและอธิบายเหตุผลไว้ให้ทุกข้อ (ข้อเหล่านี้อยู่ในคลังข้อสอบของแอปด้วยแล้ว เอกสารนี้ช่วยให้อ่านเหตุผลประกอบได้สะดวกขึ้น)
3. **ข้อที่ยังไม่สามารถยืนยันเฉลยได้** (60 ข้อ) — ไม่ได้นำเข้าคลังข้อสอบของแอป เพราะข้อมูลรูปภาพ/สัญลักษณ์สูญหายตอนแปลงไฟล์ หรือเป็นความรู้เฉพาะทางที่ต้องอ้างอิงคู่มืออุปกรณ์ แนะนำให้ทบทวนกับผู้สอนเพิ่มเติม
4. **หมายเหตุแหล่งที่มาและข้อจำกัด** — รวมถึงไฟล์ภาพสแกน 5 ไฟล์และไฟล์ตรีโกณมิติ 2 ไฟล์ที่ยังแปลงเป็นข้อสอบไม่ได้ (เนื้อหาซ้ำกับที่มีอยู่แล้วเป็นส่วนใหญ่)

## หมายเหตุด้านความปลอดภัย

- เก็บ `ADMIN_KEY` เป็นความลับ อย่าเผยแพร่ที่ใดที่เปิดเผยได้ง่าย
- คลังข้อสอบเต็ม 1,218 ข้อ อยู่ฝั่งเซิร์ฟเวอร์เท่านั้น ไม่ได้ฝังในไฟล์เว็บ (ป้องกันการคัดลอกทั้งชุด)
- อย่าลืม: หลังได้ URL เซิร์ฟเวอร์จากขั้นตอน A แล้ว ส่งกลับมาให้ผมฝังใน `index.html` ก่อนอัปโหลดขึ้น GitHub จริง มิฉะนั้นเว็บจะขึ้น "ยังไม่ได้ตั้งค่า SERVER_URL ของแอป" (ไม่เกี่ยวกับผู้ที่อัปเดตระบบเดิม เพราะ URL ฝังไว้ให้แล้วในไฟล์ที่แนบมารอบนี้)
